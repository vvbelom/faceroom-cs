# FaceRoom · кабинет управляющего

Страница, на которой управляющие студий смотрят статистику: конверсию обращений,
списки тех, кто обратился и не записался, звонки, качество переписок и отзывы.

Адрес: https://vvbelom.github.io/faceroom-cs/ — вход по общему паролю управляющих.

## Как это устроено

Репозиторий публичный, поэтому в нём **нет открытых данных**:

- `site/` — сама страница: `index.html`, `style.css`, `app.js`. Без внешних
  скриптов: графики нарисованы в SVG, сторонние библиотеки на страницу,
  расшифровывающую телефоны клиентов, не подключаются.
- ветка `data` — один файл `data.enc.json`, зашифрованный паролем управляющих
  (PBKDF2-SHA256, 600 000 итераций → AES-256-GCM). Расшифровывает его браузер
  после ввода пароля; наружу ничего не уходит.

Данные собирает и шифрует приватный репозиторий с ботами — там же вся обработка.
Каждое утро после отчёта управляющим он перезаписывает ветку `data` (одним
коммитом, чтобы ежедневные файлы не копились в истории) и присылает сигнал
`data-updated`; воркфлоу `.github/workflows/pages.yml` выкладывает страницу
вместе со свежими данными.

## Разделы

| Раздел | Что показывает | Откуда |
|---|---|---|
| Конверсия | записались / обратились по звонкам и перепискам, первичные, динамика, по студиям | вечерние срезы конверсии |
| Не записались | кто обратился и не записался — по дням и студиям, с заметкой | те же срезы |
| Звонки | принято, пропущено, перезвонили, замечания по разговорам | дневная статистика отчёта по звонкам |
| Переписки | диалоги, записи, конверсия первичных, без ответа, замечания, время ответа — по неделям | недельная статистика отчёта по перепискам |
| Отзывы | оценки и тексты отзывов | сбор отзывов |

Списки людей хранятся за последние 62 дня, цифры — за всё время.

## Пароль

Пароль задаётся секретом `CS_DASHBOARD_PASSWORD` в приватном репозитории.
Файл с данными лежит в открытом доступе, и подобрать пароль можно пытаться
офлайн, поэтому он должен быть стойким: не короче 16 символов или 4–5 случайных слов.

Сменить пароль: поменять секрет и запустить воркфлоу сборки данных вручную —
со следующей публикацией старый пароль перестанет открывать страницу.

## Проверить локально

```bash
python -m http.server 8000 --directory site
```

Положите рядом с `index.html` файл `data.enc.json`. В `.gitignore` он
перечислен, чтобы тестовые данные случайно не попали в публичный репозиторий.
